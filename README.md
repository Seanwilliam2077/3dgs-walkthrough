# 3DGS 漫游指南

一份 3D Gaussian Splatting（3DGS）通俗导读。页面开头是一张可点击的研究方向总览图，接着用三个能在浏览器里动手的小实验讲清原理，最后按六大模块给出 146 篇论文与工具的配图卡片。

**在线阅读：<https://seanwilliam2077.github.io/3dgs-walkthrough/>**

## 页面结构

1. **总览**：「3DGS 研究方向与技术关联」图。六个模块、各自的子模块和代表作都能点击：点模块或子模块跳到对应章节，点论文名直达它的卡片。方块之间的箭头标出技术关联，比如「高斯场景」「几何提取」「法线 / 可见性」。
2. **基础**：
   - 「彩色果冻豆」直觉、一颗高斯的 59 个参数、与摄影测量和 NeRF 的对比、原论文 Table 1；
   - 原理四步，其中三步可以动手：单个高斯的投影、α 混合的前后顺序、在浏览器里训练（开 / 关自适应增删对比）。
3. **六大模块**，顺序与两张总览图一致：
   1. 高效重建
   2. 组织、编辑与 LoD
   3. 压缩与高效渲染
   4. 几何与 Mesh + GS
   5. 材质分解与重光照
   6. 动态与交互

   每个模块先讲要解决的问题、主流思路和工程建议，再按子模块排出代表作（共 83 篇），其余论文收在默认折叠的「延伸阅读」里。支持搜索、按模块筛选和「只看里程碑」。
4. **其余部分**：更多应用（SLAM、自动驾驶、3D 生成）、2020–2026 时间线、工程生态与许可、读数字时的口径提醒、术语表、参考与勘误。

每张卡片都有论文链接（arXiv / 项目页 / 代码）和一张配图。配图取自论文 arXiv HTML 版的 Figure 1（多为 teaser），或者项目页、仓库里的展示图，少数由人工挑选。

## 关于配图

- 本仓库**不保存**任何论文图片，图片的版权归原作者。
- 页面通过 [images.weserv.nl](https://images.weserv.nl/) 的缓存加载 720 px 的 WebP 缩略图，原图动辄几 MB，缩略图只有几十 KB。
- 缩略图加载失败时，页面会先重试一次，再改用原图地址，仍然失败就显示按子模块绘制的示意图，卡片始终可读。
- 除配图和标题字体外，页面不加载其他外部资源：脚本、样式都在 `index.html` 里。
- 标题用思源宋体（Google Fonts 上的 Noto Serif SC），加载失败时退回系统自带的宋体，正文本来就用系统字体。

## 仓库结构

```
index.html          生成出来的页面
src/
  data.py           内容：模块 → 子模块 → 代表作 / 延伸阅读，以及时间线、生态、术语、勘误
  figures.json      每篇论文的配图地址（teasers.py 生成；"pin": true 的是人工挑选）
  teasers.py        查找配图、预热缩略图缓存
  template.html     页面骨架
  style.css         样式（浅色 / 深色）
  icons.svg         子模块图标，也用作配图加载失败时的示意图
  splat2d.js        2D 高斯泼溅：前向、解析反向、Adam、克隆 / 分裂 / 剪枝
  scenes.js         程序生成的目标图（湖景、果冻豆）
  app.js            页面交互：主题、首页动画、三个实验、图表、筛选、回到总览
  build.py          把以上文件拼成 index.html
  gradcheck.cjs     用有限差分校验 splat2d.js 的解析梯度
```

## 修改后重新生成

新增一篇论文，在 `src/data.py` 对应子模块里加一行 `W(...)`：放进 `groups` 就是代表作，放进 `extra` 就是延伸阅读。然后依次运行下面三条命令（macOS / Linux 上可能是 `python3`）。

为新论文查找配图：

```bash
python src/teasers.py
```

把新缩略图预热进缓存：

```bash
python src/teasers.py --warm
```

生成 index.html：

```bash
python src/build.py
```

`build.py` 会做以下检查：arXiv 编号格式、日期与编号是否对得上、每项是否带链接、总览图里的论文名是否存在，然后覆盖根目录的 `index.html`。某篇论文的自动配图不合适时，在 `src/figures.json` 里改它的 `src` 并加上 `"pin": true`。

改了 `splat2d.js` 的话，再跑一次梯度校验：

```bash
node src/gradcheck.cjs
```

本地预览：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 信息来源与核对方式

- arXiv 编号、标题、首版日期：逐条对照 arxiv.org。
- 会议信息：CVF Open Access 与 ECVA 的收录列表、论文页的 Comments 字段、官方代码仓库的说明。
- 许可证与项目状态：各 GitHub 仓库的 LICENSE / README，以及 Khronos 官方 glTF 仓库。
- 3DGS 原论文数字：arXiv:2308.04079 的 Table 1 与正文。

信息核对截至 2026-09-17。作者自评和厂商声明的数字在页面上都有标注。

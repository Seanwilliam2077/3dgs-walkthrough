@@ECOSYSTEM@@
用途项目做什么许可
商用前先查许可。原版 3DGS 的代码是 Inria 的非商用许可，而很多下游仓库直接把 Inria 系的光栅器（diff-gaussian-rasterization 及其变体）当作子模块，许可会跟着带过去。想做产品，底座优先选 gsplat、3DGRUT 这类 Apache-2.0 / MIT 的实现。

怎么核对的

  1. arXiv 编号、标题和首版日期：逐条对照 arxiv.org 的论文页面。
  2. 会议信息：对照 CVF Open Access（CVPR 2024/2025/2026、ICCV 2025）、ECVA（ECCV 2024）的收录列表，以及论文页的 Comments 字段和官方代码仓库的说明。
  3. 许可证与项目状态：对照 GitHub 仓库的 LICENSE、README，以及 Khronos 官方 glTF 仓库。
  4. 原论文数字：3DGS 论文 Table 1 与正文（arXiv:2308.04079，项目页）。
  5. 卡片配图：取自 arXiv HTML 版论文的第一张图（多为 teaser），或项目页的封面图，直接从原站加载，版权归原作者；本仓库不保存这些图片。

信息核对截至 @@UPDATED@@。领域变化很快，引用前请以论文和仓库的最新版本为准。

# 3DGS 漫游指南

用直觉、三个能在浏览器里动手的小实验和一张方向地图，讲清 3D Gaussian Splatting（3DGS）的原理，并按六个方向梳理 2020–2026 年的关键工作。

**在线阅读：<https://seanwilliam2077.github.io/3dgs-walkthrough/>**

## 页面里有什么

- **直觉**：「彩色果冻豆」类比、一颗高斯的 59 个参数、与摄影测量和 NeRF 的对比、原论文 Table 1 的成绩。
- **原理四步**，其中三步可以动手：
  - 单个高斯：调三个半轴和相机视角，看 3D 协方差怎样投影成屏幕上的椭圆；
  - 前后顺序：给三颗高斯换顺序，逐层查看 α、透光率和权重；
  - 浏览器里训练：同一张图，开启和关闭自适应增删各训练一遍，对比结果和 PSNR 曲线。
- **2020–2026 时间线**和**方向地图**。
- **六大方向**：重建速度、体积压缩与大场景、画质与抗锯齿、几何网格与混合渲染、编辑分割与物理、重光照与材质，另加扩展应用。共 133 项工作，其中 21 项为里程碑，支持搜索和「只看里程碑」。
- **工程生态与许可**、读数字时的口径提醒、术语表，以及对原综述的更正与更新。

首页的「3DGS」字样和第四步的拟合实验都是真的在训练：前向渲染、解析梯度、Adam 和自适应密度控制都用 JavaScript 在浏览器里实时计算，显示用 WebGL2，不支持时退回 Canvas。

## 仓库结构

```
index.html          生成出来的页面（单文件，不加载任何外部资源）
src/
  data.py           内容数据：方向、工作、时间线、生态、术语、勘误
  template.html     页面骨架
  style.css         样式（浅色 / 深色）
  splat2d.js        2D 高斯泼溅：前向、解析反向、Adam、克隆 / 分裂 / 剪枝
  scenes.js         程序生成的目标图（湖景、果冻豆）
  app.js            页面交互：主题、首页动画、三个实验、图表、筛选
  build.py          把以上文件拼成 index.html
  gradcheck.cjs     用有限差分校验 splat2d.js 的解析梯度
```

## 修改后重新生成

改完 `src/` 下的文件，运行：

```bash
python src/build.py
```

macOS / Linux 上命令可能是 `python3`。`build.py` 会检查 arXiv 编号格式、日期与编号是否对得上、每项工作是否带链接，然后覆盖根目录的 `index.html`。新增一项工作，只需在 `src/data.py` 对应方向里加一行 `W(...)`，同一分组内会自动按日期排序。

改了 `splat2d.js` 的话，再跑一次梯度校验：

```bash
node src/gradcheck.cjs
```

本地预览：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 信息来源与核对方式

- arXiv 编号、标题、首版日期：逐条对照 arxiv.org。
- 会议信息：CVF Open Access 与 ECVA 的收录列表、论文页的 Comments 字段、官方代码仓库的说明。
- 许可证与项目状态：各 GitHub 仓库的 LICENSE / README，以及 Khronos 官方 glTF 仓库。
- 3DGS 原论文数字：arXiv:2308.04079 的 Table 1 与正文。

信息核对截至 2026-09-17。作者自评和厂商声明的数字在页面上都有标注。
